# Karen Calderon — Product Designer

A responsive, one-page portfolio built with Next.js 16. It includes three clearly labeled UX/UI concept studies, original project visuals, expandable design decisions, and a contact link.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To verify a production build, run `npm run build`.

## Content

The case studies are concept explorations created to demonstrate design thinking. They do not represent shipped client work or measured outcomes. Project artwork lives in `public/assets/`; page content and interactions are in `app/page.tsx`, with styling in `app/globals.css`.
