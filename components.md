# Component Inventory

## Portfolio components

- `PortfolioHome` — page composition.
- `ProgressBar` — scroll progress indicator.
- `SiteHeader` — brand, navigation links, contact link, and mobile menu.
- `HeroSection` — eyebrow, headline, description, hero graphic, and call to action.
- `HeroGraphic` — decorative orbital SVG.
- `IconLink` — circular arrow link.
- `ArrowIcon` — horizontal and diagonal arrow variants.
- `SectionIndex` — numbered section label.
- `IntroSection` — selected work introduction.
- `WorkSection` — collection of case study cards.
- `CaseStudyCard` — case study image, summary, tags, and expand/collapse control.
- `CaseStudyDetails` — context, UX decision, UI response, and testing details.
- `ApproachSection` — approach heading and principle items.
- `AboutSection` — about copy, symbol, and traits.
- `ContactSection` — contact copy and email action.
- `SiteFooter` — copyright, descriptor, and back-to-top link.

## Storybook components

- `Button`
- `Header`
- `Page`

Portfolio content and image paths are supplied through the typed data object in `app/content.ts`.
